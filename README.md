# Kasper Bergholt

I work with old cameras, old languages and old texts: photography and what comes after it, system poetry, and programs written for hardware that no longer ships.

## Works

### Sun: 72 Poems for 72 Solar Eclipses

**[triptych](https://github.com/bergholt/triptych)**

Ten words in two word orders make seventy-two poems, one for each solar eclipse of Saros 126, a cycle that runs from 1179 to 2459. The eclipse of 12 August 2026 is the forty-eighth. A Prolog program spells out the poem's constraints and generates every combination they allow.

**In press:** *Sun: 72 Poems for 72 Solar Eclipses* (Forlaget Akse, 2026/2027), an 84-page paperback. Each of the 72 variants has its own page, with its eclipse, its letters and its partials over an A2 drone. The complete source code follows.

[About the work](https://bergholt.net/sun)

### Flora Excursoria Hafniensis

**[flora-excursoria-hafniensis](https://github.com/bergholt/flora-excursoria-hafniensis)**

A transcription of the 903-name index to Drejer's 1838 flora of Copenhagen, read with Prolog. The index files Latin and Danish names in a single alphabet and never says which translates which. But a plant's two names were set on the same page, so the page number works as a join key, and some of the pairs can be recovered.

[About the work](https://bergholt.net/flora)
